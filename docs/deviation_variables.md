# Deviation Variables

To linearise the nonlinear system, small deviations from the operating point are defined.

Let the operating point be:

- x₁ = x₀  
- x₂ = v₀  
- x₃ = i₀  
- u = u₀  

Define the deviation variables:

- x̄₁ = x₁ - x₀  
- x̄₂ = x₂ - v₀  
- x̄₃ = x₃ - i₀  
- ū = u - u₀  

Since v₀ = 0:

- x̄₂ = x₂  

These variables represent small deviations about the operating point and will be used to derive the linearised system.
