# Deviation Variables

To linearise the nonlinear system, small deviations from the operating point are defined.

Let the operating point be defined by:

- x₁ = x₁,₀  
- x₂ = x₂,₀  
- x₃ = x₃,₀  
- u = u₀  

Define the deviation variables:

- x̄₁ = x₁ - x₁,₀  
- x̄₂ = x₂ - x₂,₀  
- x̄₃ = x₃ - x₃,₀  
- ū = u - u₀  
- ȳ = y - y₀  

Since x₂,₀ = 0:

- x̄₂ = x₂  

These variables represent small deviations about the operating point and will be used to derive the linearised model.
