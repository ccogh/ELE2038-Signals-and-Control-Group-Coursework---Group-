# Nonlinear System Model

## 1. System Description

The system consists of a ball rolling along an inclined plane under the influence of gravity, a spring, viscous damping, and a magnetic force generated by an electromagnet.

The electromagnet is driven by an electrical circuit, and the ball position is measured using a sensor.

The system is nonlinear because:
- the magnetic force depends nonlinearly on both position and current
- the inductance of the electromagnet depends on position

---

## 2. Variables and Parameters

### State variables
- x1 = x : position (m)  
- x2 = v : velocity (m/s)  
- x3 = i : current (A)  

### Input
- u = V : applied voltage (V)

### Output
- y: measured position (from sensor)

---

## 3. Modelling Assumptions

1. The ball rolls without slipping  
2. The ball is a solid sphere (I = 2/5 m r^2)  
3. Spring and damper act along the incline  
4. Magnetic force acts toward x = δ  
5. Air resistance neglected  
6. Sensor is first-order (modelled separately)  
7. The term i(dL/dt) is neglected (slow inductance variation)

---

## 4. Nonlinear Mechanical Model

### Forces along incline

- Gravity: Fg = m g sin(φ)  
- Spring: Fs = -k(x - d)  
- Damping: Fd = -b v  
- Magnetic: Fmag = c x3^2 / (δ - x)^2  

---

### Final nonlinear equation

ẍ = (5 / 7m) [ m g sin(φ) - k(x - d) - b v + c x3^2 / (δ - x)^2 ]

---

### State-space form

ẋ1 = x2  

ẋ2 = (5 / 7m) [ m g sin(φ) - k(x1 - d) - b x2 + c x3^2 / (δ - x1)^2 ]

---

## 5. Nonlinear Electrical Model

Inductance:

L(x1) = L0 + L1 e^(-α(δ - x1))

KVL:

V = R i + d/dt (L(x)i)

Neglecting the term i(dL/dt), the electrical dynamics are approximated by:

ẋ3 = (u - R x3) / L(x1)

---

## 6. Final Nonlinear State-Space Model

States:

x = [x1, x2, x3]^T

Input:

u = V

System:

ẋ1 = x2  

ẋ2 = (5 / 7m)[ m g sin(φ) - k(x1 - d) - b x2 + c x3^2 / (δ - x1)^2 ]  

ẋ3 = (u - R x3) / L(x1)  

The state x1 represents the true position of the ball.

---

## 7. Sensor Model (separate block)

The position sensor is modelled as a first-order system:

τm ẏm + y_m = x1  

or:

ẏm = (x1 - y_m) / τm  

The measured output of the system is:

y = y_m

---

## 8. Note for Linearisation

The full system input is voltage V.

In the linearisation and control design, the full 3-state system (x1, x2, x3) is used as the plant, and the sensor is treated as a separate block.
